Adds Lock Screen Studio 0.0.1, a lock-screen customization mod with clock layouts, weather/widget cards and media themes.

Includes eight pixel clock/date compositions, desktop-inspired themes, independent fonts and positioning controls, and Studio weather cards with themed condition icons. Windows remains the weather data source and retains the native media controls. Selecting Windows default restores the native widget card.

Tested on my Windows 11 26H2 x64 setup with Windhawk 1.7.3. The standalone source compiles with Windhawk's compiler; placement and weather condition tests pass. Screenshots and setup instructions are in the embedded readme.

The inherited clock engine's MIT notice and Pixelify Sans's OFL-1.1 notices are retained in the source. No wallpaper or external weather provider is included.
